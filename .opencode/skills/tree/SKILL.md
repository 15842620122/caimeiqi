# 生成目录树

输出当前工作目录的文件与文件夹层级结构，帮助快速了解项目布局。

## 步骤

1. 确认目标目录：
   - 默认使用当前工作目录（`d:\GJ\1`）。
   - 若用户指定了子目录，切换到该目录或在命令中指定路径。

2. 生成树结构（按优先级尝试）：
   - 优先使用系统自带的 `tree` 命令（Windows 内置）：
     - `tree /F` 显示文件夹 + 文件。
     - `tree` 仅显示文件夹。
     - 如需保存到文件：`tree /F > tree.txt`。
   - 若 `tree` 不可用或需要更灵活的输出，使用 PowerShell：
     - `Get-ChildItem -Recurse | Select-Object FullName` 列出全部路径。
     - 或用 `tree /F` 在 PowerShell 中同样可用（Windows 下）。

3. 过滤无关内容：
   - 默认排除 `.git`、`.opencode`、`node_modules` 等隐藏目录或依赖目录。
   - 若用户明确要求包含全部内容（包括隐藏文件），则不过滤。
   - 若用户只关心某类文件（如 `.html`），用 `tree /F | findstr /i ".html"` 或 PowerShell 过滤。

4. 展示结果：
   - 将生成的树结构直接输出给用户。
   - 若结果较长（超过 100 行），可分段展示或提示用户查看生成的文件。
   - 用简短文字说明目录结构要点（如顶层有哪些主要文件夹、文件总数等）。

## 注意

- Windows 的 `tree` 命令使用 GBK 编码输出，若终端乱码，先执行 `chcp 65001` 切换到 UTF-8。
- 本项目为静态站点，目录层级通常较浅，`tree /F` 足以清晰展示。
- 仅展示结构，不要删除、移动或修改任何文件。
