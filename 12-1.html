CSS 变量（自定义属性）

CSS 变量以 -- 开头，用 var() 读取。先在 :root 里定义一次，所有元素都能继承使用；改一处，处处生效。本页由蔡美琪完成，演示 CSS 变量的定义、继承、备用值、calc() 运算与主题切换。

一、定义与使用

/* 定义：必须以 -- 开头，写在 :root 或任意选择器里 */ :root { --caimeiqi-primary: #2563eb; --caimeiqi-radius: 14px; } /* 使用：var(变量名) 可以用在任何属性值的位置 */ .caimeiqi_box { color: var(--caimeiqi-primary); border-radius: var(--caimeiqi-radius); }
我用 var(--caimeiqi-primary) 上色、var(--caimeiqi-radius) 做圆角、var(--caimeiqi-gap) 做内边距 —— 三个变量都定义在 :root 上。
--caimeiqi-primary
--caimeiqi-primary-light
--caimeiqi-accent

同一个变量出现在背景、文字、边框、阴影上，只要改 :root 里的值，整页配色一起变。

二、备用值（默认值）

font-size: var(--caimeiqi-not-defined, 16px);
变量 --caimeiqi-not-defined 没有定义，于是使用第二个参数 16px。已定义的变量则忽略备用值：var(--caimeiqi-primary, red) 仍然是蓝色。

三、calc() 与变量

calc(gap × 6)
calc(gap × 12)
calc(gap × 18)

变量本身没有单位，calc() 负责把它变成具体长度：--caimeiqi-gap 为 16px，所以 calc(var(--caimeiqi-gap) × 12) = 192px。

四、继承与局部覆盖

父元素：颜色 var(--caimeiqi-primary) = #2563eb（来自 :root）
子元素里重新写 --caimeiqi-primary: #db2777，只影响自身及后代，父元素不变。

五、换一套变量 = 换主题

这个盒子把三个变量换成了绿色系，鼠标悬停时又在自己作用域内换成紫色系 —— 样式规则一条没改，只改了变量值。
悬停我试试
  • 命名规则：必须以 -- 开头，区分大小写，不能加引号
  • 读取方式：只能用 var(--名字)，第二个参数是备用值
  • 继承特性：默认继承父元素，子元素重新定义即可覆盖，只影响自身作用域
  • 使用限制：只能用在属性值位置，不能当选择器、属性名或拼接出新选择器
  • 常见场景：统一配色与间距、主题切换（配 @media 或 :hover）、配合 calc() 做运算
