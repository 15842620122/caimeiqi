移动端底部导航 · 字体图标

这个页面使用 iconfont 字体图标（font/iconfont.css）实现移动端固定底栏；统计和植物识别按参考图分别使用柱状图与相机图标，宽度随屏幕自适应。本页由蔡美琪完成。

二、固定定位 + 全屏宽度 + 自适应等分

.caimeiqi_tabbar { position: fixed; left: 0; bottom: 0; width: 100%; display: grid; grid-template-columns: 1fr 1fr 1.45fr 1.9fr; padding-bottom: env(safe-area-inset-bottom); }

三、数字徽章与右上角红点

.caimeiqi_icon_wrap { position: relative; width: 28px; height: 28px; } .caimeiqi_badge { /* 数字徽章，盖在图标右上角 */ position: absolute; top: -6px; right: -12px; min-width: 18px; height: 18px; border-radius: 999px; background: #ff3b30; color: #fff; font-size: 11px; line-height: 18px; text-align: center; box-shadow: 0 0 0 2px #fff; /* 白描边，压在图标上也看得清 */ } .caimeiqi_dot { /* 红点，绝对定位在图标右上角 */ position: absolute; top: -1px; right: -8px; width: 8px; height: 8px; border-radius: 50%; background: #ff3b30; }

四、移动端适配要点

  • viewport：<meta name="viewport" content="width=device-width, initial-scale=1"> 让页面按设备宽度渲染
  • 全屏宽度：position: fixed 配 left: 0; bottom: 0; width: 100vw，导航条始终横跨整个视口
  • 自适应布局：底栏用 CSS Grid 按参考图分配四个区域，最后的“添加植物”按钮更宽；320px、375px、414px 屏幕均铺满宽度
  • 字号缩放：图标 font-size: clamp(22px, 6vw, 26px)、文字 clamp(11px, 3vw, 13px)，随屏宽平滑变化不溢出
  • 安全区：padding-bottom: env(safe-area-inset-bottom) 适配 iPhone 底部手势条
  • 避免遮挡：正文容器 padding-bottom: 130px，滚动到底时内容不会被固定导航盖住
  • 操作按钮：添加植物项使用圆形加号和绿色圆角按钮，与普通图标导航形成层级
  • 字体图标特点：图标是字体字符，用 font-size 控制大小、color 控制颜色，选中态一处改色即可
