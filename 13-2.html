Lucide SVG 图标

Lucide 是一套开源的图标 SVG 集合，每个图标都是一段 <svg> 标记（viewBox + path + 描边）。本页把官方 CDN 文件 lucide.min.js 下载到本地 cdn/ 目录，页面里写 <i data-lucide="图标名"> 占位，脚本会把它替换成真正的 SVG 元素。因为是 SVG，颜色（currentColor）、大小（width/height）、线条粗细（stroke-width）都能用 CSS 随意控制。本页由蔡美琪完成。

一、基本用法

<script src="./cdn/lucide.min.js"></script> <i data-lucide="house"></i> /* 占位符，稍后被替换成 svg */ <i data-lucide="heart"></i> <script> lucide.createIcons(); /* 把所有 data-lucide 元素渲染成 SVG */ </script>

二、从占位符到 SVG

/* 渲染前（源码里写的） */ <i data-lucide="leaf"></i> /* 渲染后（打开开发者工具可以看到） */ <svg class="lucide lucide-leaf" xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"> <path d="M11 20a10 10 0 0 0 10-10 25.9 25.9 0 0 0-1.04-7.281 ..."/> <path d="M2 21a5 5 0 0 1 2.911-4.544 ..."/> </svg>

三、用 CSS 控制 SVG 大小

.caimeiqi_sz4 svg { width: 52px; height: 52px; } /* 改宽高即可 */ .caimeiqi_sw3 svg { stroke-width: 3.5; } /* 改线条粗细 */

四、用 currentColor 换颜色

.caimeiqi_c_red { color: #ef4444; } /* svg 的 stroke="currentColor" 会取到它 */

  • 图标形式：每个图标就是一段 <svg> 标记，由 viewBox 定义 24×24 画布、<path> 描出轮廓
  • 接入方式：本地引入 ./cdn/lucide.min.js，写 data-lucide 占位符，lucide.createIcons() 一次性替换成 SVG
  • 矢量缩放：改 width / height 即可任意放大缩小，永远不模糊，也不需要下载多套尺寸
  • 颜色继承：stroke="currentColor" 让描边跟着 CSS 的 color 走，文字什么颜色图标就什么颜色
  • 线条可调：stroke-width、stroke-linecap 都是属性，CSS 可覆盖，能做出细线、粗线等风格
  • 与字体图标对比：字体图标是一个字符（只能整体换色），SVG 是真实 DOM（可分别控制每段路径、加动画、改结构）
