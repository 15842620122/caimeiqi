🎯 当前数组 cmq_arr = [1,2,3,4,5]

🔴 会修改原数组 🟢 不修改原数组（返回新值）

一、增删改元素 修改原数组

push() 末尾追加

cmq_arr.push(6, 7); // 返回新长度
等待运行…

pop() 末尾删除

cmq_arr.pop(); // 返回被删元素
等待运行…

unshift() 开头插入

cmq_arr.unshift(0); // 返回新长度
等待运行…

shift() 开头删除

cmq_arr.shift(); // 返回被删元素
等待运行…

splice() 万能增删改

// splice(start, deleteCount, item1, item2, ...) cmq_arr.splice(2, 1, 99); // 从索引2开始删1个，插入99
等待运行…

二、查找元素 不修改

indexOf() 查找索引

cmq_arr.indexOf(3); // 找到返回索引，否则 -1
等待运行…

includes() 是否包含

cmq_arr.includes(3); // 返回 true / false
等待运行…

find() 找第一个符合的元素

cmq_arr.find(x => x > 3); // 返回元素本身，否则 undefined
等待运行…

findIndex() 找索引

cmq_arr.findIndex(x => x > 3); // 返回索引，否则 -1
等待运行…

some() 有一个满足？

cmq_arr.some(x => x % 2 === 0); // 至少一个满足则 true
等待运行…

every() 全部满足？

cmq_arr.every(x => x > 0); // 全部满足才 true
等待运行…

三、遍历 & 转换 返回新数组/值

map() 映射每个元素

cmq_arr.map(x => x * 2); // 每个元素乘 2，返回新数组
等待运行…

filter() 过滤

cmq_arr.filter(x => x % 2 === 1); // 只保留奇数
等待运行…

reduce() 累积求和

cmq_arr.reduce((a, b) => a + b, 0); // 求和，0 为初始值
等待运行…

forEach() 遍历执行

cmq_arr.forEach((x, i) => { cmqLog(i + ":" + x); }); // 无返回值，只是执行
等待运行…

四、排序 & 其他实用方法

sort() 排序 修改

cmq_arr.sort((a, b) => a - b); // 升序。注意：默认按字符串排！
等待运行…

reverse() 反转 修改

cmq_arr.reverse();
等待运行…

slice() 切片 不修改

cmq_arr.slice(1, 4); // [start, end) 含头不含尾
等待运行…

concat() / join()

cmq_arr.concat([6, 7]); cmq_arr.join("-");
