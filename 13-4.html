移动端底部导航 · SVG 图标

同一个 iconfont 项目换成 SVG Symbol 方式使用：iconfont.js 把所有 <symbol> 雪碧图注入页面，导航中使用 <use href="#icon-xxx"> 引用。底部按参考图安排设置、统计、植物识别和添加植物四项，固定全屏宽度，随移动端屏幕自适应。本页由蔡美琪完成。

一、图标与结构（Symbol + use）

前三项使用 iconfont 提供的 SVG Symbol；添加植物项是醒目的绿色圆角按钮（symbol id 引用方式）：

#icon-settings
#icon-gongneng
#icon-yanghu
#icon-addNode
<script src="./font/iconfont.js"></script> /* 注入 symbol 雪碧图 */ <nav class="caimeiqi_tabbar"> <div class="caimeiqi_tab_item caimeiqi_is_active"> <span class="caimeiqi_icon_wrap"><svg class="caimeiqi_tab_icon"><use href="#icon-settings"></use></svg></span> <span class="caimeiqi_tab_text">设置</span> </div> <div class="caimeiqi_tab_item"> <span class="caimeiqi_icon_wrap"><svg class="caimeiqi_tab_icon"><use href="#icon-gongneng"></use></svg></span> <span class="caimeiqi_tab_text">统计</span> </div> <div class="caimeiqi_tab_item"> <span class="caimeiqi_icon_wrap"><svg class="caimeiqi_tab_icon"><use href="#icon-yanghu"></use></svg></span> <span class="caimeiqi_tab_text">植物识别</span> </div> <div class="caimeiqi_tab_item caimeiqi_tab_action"> <span class="caimeiqi_plus">+</span> <span class="caimeiqi_tab_text">添加植物</span> </div> </nav> /* SVG 图标本身：尺寸随屏幕，颜色跟随文字 */ .caimeiqi_tab_icon { width: clamp(22px, 6vw, 26px); height: clamp(22px, 6vw, 26px); fill: currentColor; filter: grayscale(1); /* 将 iconfont 彩色符号转为参考图的灰色图标 */ }

二、固定定位 + 全屏宽度 + 自适应等分

.caimeiqi_tabbar { position: fixed; /* 相对视口固定，不随页面滚动 */ left: 0; bottom: 0; width: 100%; /* 占满视口宽度 */ display: grid; /* 按参考图自适应排列 */ padding-bottom: env(safe-area-inset-bottom); /* 刘海屏安全区 */ } .caimeiqi_tabbar { grid-template-columns: 1fr 1fr 1fr 1.9fr; } .caimeiqi_tab_action { background: #40b34f; color: #fff; }

三、数字徽章与右上角红点

.caimeiqi_icon_wrap { position: relative; width: 28px; height: 28px; } .caimeiqi_badge { /* 数字徽章，盖在 SVG 右上角 */ position: absolute; top: -6px; right: -12px; min-width: 18px; height: 18px; border-radius: 999px; background: #ff3b30; color: #fff; font-size: 11px; line-height: 18px; text-align: center; box-shadow: 0 0 0 2px #fff; /* 白描边，压在图标上也看得清 */ } .caimeiqi_dot { /* 红点相对 icon_wrap 定位在图标右上角 */ position: absolute; top: -1px; right: -8px; width: 8px; height: 8px; border-radius: 50%; background: #ff3b30; }

四、实现要点

  • Symbol 雪碧图：iconfont.js 把 <symbol id="icon-xxx" viewBox="0 0 1024 1024"> 全部注入页面，<use> 引用后浏览器生成 SVG 影子内容
  • 真实 DOM：图标是 <svg> 元素而不是字体字符，可被 CSS 改 width / height / fill / transform，也能用 JS 操作路径
  • 矢量缩放：symbol 自带 viewBox="0 0 1024 1024"，外部只给宽高即可任意缩放，任何屏幕上都不模糊
  • 图标风格：绿色图标和添加植物按钮对应参考图的植物工具界面
  • 全屏宽度：position: fixed 配 left: 0; bottom: 0; width: 100vw，导航条始终横跨整个视口
  • 自适应布局：CSS Grid 将前三项等宽排列，最后的添加按钮获得更多空间，适应手机宽度
  • 移动端细节：viewport meta、clamp() 字号、env(safe-area-inset-bottom) 安全区、正文 padding-bottom: 130px 防遮挡
  • 添加入口：带圆圈的加号与圆角按钮构成独立的主要操作
