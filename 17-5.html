两种定时器：setTimeout 一次性延迟执行 / setInterval 周期性循环执行

📘 两种定时器对比

setTimeoutsetInterval
⏰ 一次性，到点只执行 1 次🔁 周期性，每隔 N ms 执行 无限次
返回值是定时器 ID（数字）同样返回定时器 ID
用 clearTimeout(id) 取消用 clearInterval(id) 取消
常用于：延迟弹窗、防抖、动画一次性跳转常用于：时钟、倒计时、轮播、进度条、轮询
⚠️ 两者都不会阻塞主线程！浏览器是单线程 + 事件循环，定时到了也得等主线程空闲才执行回调。

🔔 延迟弹窗 setTimeout

setTimeout 只触发一次，到点后自动停止。如果在等待期间清除掉定时器，弹窗就不会出现。
🎉 哈喽！ 你看到这条消息，是因为 3 秒前点了「延迟弹窗」按钮，
setTimeout 到点自动触发了。
var timer = setTimeout(function() { // 只在 3000ms 后执行一次 showBanner(); }, 3000); function cancelIt() { clearTimeout(timer); // 还没到点就取消，不会弹窗 }
