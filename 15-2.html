一、条件语句（分支结构）

根据不同条件执行不同代码块，控制程序的分支走向。

1. if 语句

// 单分支：条件为 true 时执行 var cmq_age = 18; if (cmq_age >= 18) { cmqLog("成年了 🎉"); }

2. if - else 语句

// 双分支：二选一 var cmq_score = 75; if (cmq_score >= 60) { cmqLog("及格 ✅"); } else { cmqLog("不及格 ❌"); }

3. if - else if - else 语句

// 多分支：依次判断 if (cmq_score >= 90) { cmqLog("优秀 🏆"); } else if (cmq_score >= 80) { cmqLog("良好 👍"); } else if (cmq_score >= 60) { cmqLog("及格 🙂"); } else { cmqLog("加油 💪"); }

4. switch 语句

// 多分支：匹配值相等 var cmq_day = 3; switch (cmq_day) { case 1: cmqLog("周一 🌅"); break; case 2: cmqLog("周二 🌞"); break; case 3: cmqLog("周三 🌤️"); break; case 4: cmqLog("周四 ⛅"); break; case 5: cmqLog("周五 🌆"); break; default: cmqLog("周末 🎉"); }
switch 要点：每个 case 后面要跟 break，否则会"穿透"到下一个 case。 default 相当于 if-else 最后的 else。

二、循环语句（重复结构）

重复执行一段代码，直到条件不再满足。

1. for 循环（最常用）

// for(初始化; 条件; 更新) for (var i = 1; i <= 5; i++) { cmqLog("第" + i + "次"); }

2. while 循环

// 先判断，再执行 var n = 1; while (n <= 3) { cmqLog("n = " + n); n++; }

3. do - while 循环

// 先执行，再判断（至少执行一次） var d = 1; do { cmqLog("do: " + d); d++; } while (d <= 2);

4. for...of 循环（遍历数组）

var fruits = ["🍎", "🍌", "🍇"]; for (var fruit of fruits) { cmqLog(fruit); }

🔑 break 和 continue

// break：立即跳出整个循环 for (var i = 1; i <= 10; i++) { if (i === 5) break; // 到 5 就停 cmqLog("break: " + i); } // continue：跳过本次，继续下一次 for (var j = 1; j <= 6; j++) { if (j % 2 === 0) continue; // 跳过偶数 cmqLog("continue: " + j); }
死循环风险：while / do-while 循环中，循环体内部必须改变条件变量，否则条件永远为 true，程序卡死！
