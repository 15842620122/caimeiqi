Font Awesome 字体图标

Font Awesome 把成千上万个图标做进一个字体文件，每个图标就是字体里的一个字符，浏览器通过 :before 伪元素的 content 把它打出来。因为是字体，所以它像文字一样可以改大小、改颜色、加阴影，缩放永远清晰。本页由蔡美琪完成，图标库文件已下载到本地 cdn/font-awesome/ 目录，离线也能显示。

一、基本用法

<link rel="stylesheet" href="./cdn/font-awesome/css/all.min.css"> <i class="fa-solid fa-house"></i> /* 实心 solid */ <i class="fa-regular fa-heart"></i> /* 线条 regular */ <i class="fa-brands fa-github"></i> /* 品牌 brands */

二、三种样式前缀

fa-solid 实心
fa-regular 线条
fa-brands 品牌

同一个图标名（如 heart）在不同前缀下是同一个字形的不同画法，实心字重最全，线条和品牌需要各自的字体文件。

三、像文字一样改大小、改颜色

/* 图标 = 字体，font-size 和 color 直接生效 */ .caimeiqi_s4 { font-size: 52px; color: #16a34a; }
14 / 24 / 36 / 52 px
green / red / amber / purple
通知图标和右边这段文字同处一行、同一字号

  • 实现原理：图标是字体文件中的字符，由 @font-face 加载，:before 的 content 输出对应编码
  • 类名结构：fa-solid / fa-regular / fa-brands 选字重，fa-图标名 选具体图标
  • 字体图标优点：体积小、可缓存，像文字一样用 font-size、color 控制，任意缩放不模糊
  • 局限：一次只能显示一个字形，不能做出双色、渐变等复杂效果，依赖字体文件加载成功
  • 本地引用：本页链接 ./cdn/font-awesome/css/all.min.css，字体在 ../webfonts/ 相对路径下，完全离线可用
