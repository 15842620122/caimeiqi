🔍 JSON vs JS 对象 的区别

✅ 合法 JSON

{
  "name": "Tom",
  "age": 20
}

❌ 非法 JSON（单引号）

{
  'name': 'Tom',
  'age': 20
}

❌ 非法 JSON（函数）

{
  "say": function() {
    alert("hi")
  }
}

❌ 非法 JSON（注释）

{
  // 这是注释
  "x": 1
}
